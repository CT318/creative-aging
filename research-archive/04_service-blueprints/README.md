# 04 服務藍圖（Service Blueprints）

**定位**：使用者歷程步驟、接觸點渠道矩陣、介入機會點分析。

## 記錄內容

- **歷程階段**：使用者從開始到結束經過的每個階段（`stages`）。
- **前台接觸點**：使用者看得到、摸得到的渠道（App、硬體、人員、場域）。
- **後台流程**：支撐前台運作、使用者看不到的作業與系統。
- **介入機會點**：哪一個階段的哪個痛點，值得設計介入（`opportunities`）。

## 怎麼記

1. 一張藍圖 = `data/` 裡一個檔案，複製 `blueprint-template.json`。
2. `persona` 填這張藍圖服務的 Persona 代號（對應 03 階段）。
3. `stages` 每個階段一筆，依時間順序排列。
4. 圖檔（藍圖原圖）請放同資料夾的 `images/`，路徑寫進 `sources`。
