# 02 田野調查（Field Research）

**定位**：田野調查、專家訪談逐字稿萃取、課堂觀察量化數據。

## 記錄內容

- **田野場域**：去了哪裡、什麼時間、觀察了什麼情境。
- **訪談對象**：身分、背景、與研究主題的關係（需匿名者請用代號）。
- **洞察紀錄**：從逐字稿萃取的關鍵引言（`quotes`）與歸納出的洞察（`insights`）。
- **量化數據**：課堂觀察的次數、時長、人數等（`metrics`）。

## 怎麼記

1. 一次訪談或一次觀察 = `data/` 裡一個檔案，複製 `interview-template.json`。
2. `fieldType` 填 `expert-interview`、`field-observation`、`classroom-observation` 其中之一。
3. 逐字稿全文不要貼進 JSON；放在同資料夾的 `transcripts/` 並於 `sources` 註明檔名，JSON 只留萃取後的引言與洞察。
4. 涉及個資請先匿名化再入庫。
