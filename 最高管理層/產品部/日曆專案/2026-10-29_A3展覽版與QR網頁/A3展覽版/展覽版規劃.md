# A3 展覽版規劃（草案，2026-10-29，待 CEO 確認）

## 規格
- A3 橫式 420 × 297 mm，實際尺寸輸出（HTML 以 mm 做版、匯出 PDF 不縮放；另附 PNG 預覽）。
- 與日曆同風格（取自 `草模/程式/make_calendar5.py`）：底色 `#F2E9D5`、淺橡木 `#DEC6A0`、墨色 `#2E2218`／`#4D3B2C`、朱紅 `#A33F2A`（日期章、重點）、奶油 `#FBF5E6`、灰綠小點當進度。標題思源宋體 Black，內文思源黑體 Medium，數字 Georgia Bold。全中文、無句號、給長輩讀。
- 前一版一頁版（藍白 16:9）的配色不沿用，改為日曆的暖米色木質調。

```
┌──────────────────────────────────────────────────────────────┐
│ 跟著日曆去旅行｜選一座想去的城市，收藏成自己的世界   （標題帶）  │
├────────────────────────────┬─────────────────────────────────┤
│                            │  掃 QR，看這座城市              │
│   主圖（棚拍：三座底座、    │  ① 掃描  ② 城市介紹  ③ 大家的印象 │
│   零件、日曆卡）           │  （背面實景 + 兩張手機介面）      │
│   約 60% 寬                │                                 │
├────────────────────────────┴─────────────────────────────────┤
│ 一本日曆，兩週一座城：選主題包→割下創作→認識城市→插上底座→掃 QR→收藏 │

```
- 左：主圖當英雄圖，下方可小標「台北／東京／雪梨」對應實物。

- 下：流程列沿用一頁版的六步，改成日曆風格小圖＋短字。
- 一頁版上半的「旅遊→主題包→數位／實體」概念圖，A3 展覽版暫不放（版面給主圖與介面）；若要保留，壓縮成標題下一行字。
