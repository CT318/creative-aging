# 製作規範（日曆專案所有切割檔都要對齊這裡）

> 2026-11-12 CEO 指示：測試階段一律用**台科大切割間的快切機**（刀片切，不是雷射），檔案規範以本資料夾的 PDF 為準。

## 快切機重點（摘自 `台科大切割間【檔案製作規範&收費方式】.pdf` 第 1、3 頁）
- 機器：能被美工刀切斷的材料都可切（紙、瓦楞紙、泡棉）→ **刀片切，沒有焦痕**。
- 尺寸上限：1300 × 1300 mm。
- 檔案：以 AI 製作、文字建立外框，**存成 PDF**。
- 線色（RGB）：**切線＝紅 R255 G0 B0**、**壓線＝綠 R0 G255 B0**、**L 型對位線＝黑 R0 G0 B0**。
- 檔案**左下角**畫拉到底的 L 型直線；先印刷的輸出檔，左下角也要有**同一條 L 型線**，用來和切割檔對齊。
- 線段必須是**單一直線，不可重複、相接、重疊**。
- 收費：依切割長度，校內 NT$0.03／mm、校外 0.06／mm；現場收費，自備零錢。

## 不適用
- 第 2 頁是雷切機（壓克力、密集板、皮革；存 AI8），日曆專案不用。

## 尚未寫在規範裡、要問助教
- 線寬要多細？
- L 型線離版面邊緣多少、印刷與切割的對位誤差大約多少？
- 留點（小連接點）最小可以多短？
- 能不能直接收「非 Illustrator 產生」的 PDF？

## 用什麼軟體做（2026-11-12 判斷）
- 規範寫「以 AI 製作」是慣用說法，機器讀的是 PDF 的線條與顏色；不一定要 Illustrator。
- 本專案做法：主持 Claude 用程式產出 PDF 並自動檢查（顏色、重疊線）；CEO 用 **Affinity**（電腦已安裝）開檔抽查顏色。若用 Affinity 修改後匯出，色彩要選 **RGB**。

## 本專案的切割設計規範（工業設計師經驗值，刀片切 200～250 克紙；**試切後再調**）
| 項目 | 建議值 |
| --- | --- |
| 線寬 | 0.1 mm（約 0.25 pt）細線；刀沿線中心走，線寬不影響切割 |
| 最細部位 | ≥ 1.5 mm（1 mm 可試，易撕裂） |
| 內角 | 最小內角 ≥ 30°，尖角加 0.5 mm 小圓角 |
| 小洞、小缺口 | ≥ 2 mm |
| 留點（連接點） | 每件 2～4 個、每個 0.5～1 mm，放直線邊、不放轉角 |
| 零件間距 | ≥ 3 mm |
| 離紙邊 | ≥ 10 mm |
| 插槽寬 | 紙厚＋0.1～0.2 mm（紙厚要先量） |
| 印刷線稿 | 外輪廓不印線，讓切線當邊，對位偏一點也看不出來 |
