# 給 Gemini 的上色提示詞（台北 v5）

**要上傳的圖**：`預覽/給Gemini上色_組裝線稿.png`（八件零件插在六角底座上的正面線稿，純白背景）

> 背景我先照「純白」寫（你的語音稿這一句我沒聽清楚，如果要別的背景，改【背景】那一行就好）。

## 提示詞（整段貼上）

```
請替我上傳的這張線稿上色。這是一個紙雕模型的正面圖：很多片白色厚紙片前後插在一個六角形紙底座上，疊成一座小小的台北——後面是山，中間是高樓和老公寓，前面是廟、紅磚老街屋、大樹和台灣藍鵲、夜市攤、歪腰郵筒、杜鵑花和機車。

【最重要】完全保留原圖的構圖、每一片紙的輪廓、位置、比例和所有線條，不要增加、刪除、移動或重畫任何物件，不要改變視角。只做「上色」這一件事。

【畫法】透明水彩手繪風格，像是真的用水彩筆在厚水彩紙上一片一片塗出來的：
- 顏色薄而透明，看得到紙的紋理；每一塊顏色的邊緣略深、中間略淡，有自然的水痕與暈染
- 允許一點點塗不滿的留白和筆觸，不要平塗、不要漸層網點、不要數位噴槍感、不要 3D 渲染
- 原本的鉛筆線稿要保留、看得見，顏色不要蓋掉線條
- 每一片紙之間保留原圖的淡淡陰影，看得出是一層一層的紙片

【配色】低彩度、溫柔、耐看的文青色調，整體不超過八個主要顏色：
- 山：由遠到近三層，灰藍綠 → 灰綠 → 較深的墨綠
- 高樓：很淡的灰藍與米白，窗戶淡藍灰
- 老公寓：米色、淡土黃、淺灰粉，鐵窗和水塔用暖灰
- 廟：屋頂磚紅偏橘，柱子與門朱紅，牆面米白
- 老街屋：紅磚色與米白相間
- 大樹：兩三種深淺的灰綠；樹幹暖褐色
- 台灣藍鵲：身體靛藍、頭黑、嘴和腳紅、尾巴尖端白
- 夜市攤：遮雨棚磚紅與米白相間，燈籠紅
- 郵筒：一綠一紅；杜鵑花：霧粉紅配深綠葉；機車：芥末黃
- 六角底座：保持紙的米白色，底座上的「台北」兩個字保持深色不變

【背景】純白色背景，底座下方只留一點很淡的陰影，不要加任何場景、桌面、文字或邊框。

【輸出】與原圖相同的構圖與比例，高解析度。
```

## 如果結果不理想，可以追加的一句
- 顏色太濃太豔：「請把所有顏色的彩度降低三成，更透明一點，多留一些紙的白。」
- 線條被蓋掉或被重畫：「請不要改動任何線條，只在線條之間填上水彩顏色。」
- 物件被改形狀：「請嚴格依照原圖的輪廓，不要重新設計任何物件。」
- 太像電腦平塗：「請加強手繪水彩的水痕、暈染和筆觸，每一塊顏色邊緣略深。」
