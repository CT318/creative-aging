# 明信片專案（世界城市日曆）：進度與歷程

> 旬常「藝術創齡－樂齡畫畫生活」專題的產品提案之一。本資料夾記錄這個提案從發想到二審草模的全部過程、規格與產出。最後更新：2026-10-28。

## 一、提案是什麼
- **要解決的問題**：幫助退休後的樂齡族群，讓藝術成為生活的一部分，無壓力且低負擔地長期參與日常藝術創作，達到「藝術創齡」。
- **核心想法**：旅遊是許多退休者的共同經驗。使用者**自選主題包**（世界、台灣、日本、澳洲⋯），依自己或親友的喜好選想了解的城市，因為是自己想去的地方，所以想把它完成。
- **數位與實體並行**：實體是可收藏、可擺在家裡和家人聊天的城市小模型；數位是掃 QR 進入城市頁，看介紹與大家的印象、連結同樣想法的人。
- **產品形式**
  - **一包＝一座城市＝兩週**；一個主題包是一本撕頁日曆，每 14 頁換一座城市。
  - 日曆一頁一天、兩頁一組：**單數頁**是當天要割下、自己上色的紙零件（線稿）；**雙數頁**是城市介紹，七組由淺入深。
  - 七件零件（地標、街屋、列車、山⋯）插在**六角形紙底座**的七個錯落插槽，由前到後由矮到高；最後方最高那件背面放 QR。
  - 底座可拼接，擺成錯落的小城市群。

- **尺寸**：六角底座對邊 100 mm、側牆高 12 mm；零件寬不超過 75 mm、高 45 到 90 mm（含卡榫 8 mm）；插槽長＝零件卡榫寬＋2 mm、插槽寬 0.8 mm（依卡紙厚度調）。經程式從 PDF 量測，日曆頁、零件圖、底座尺寸都與設定相符。
- **台北七件**（由矮到高，內容由淺入深）：夜市小吃攤→捷運列車→迪化街老街屋→龍山寺→總統府→象山步道→台北 101。

## 四、設計決策紀錄
- **對象是長輩**：日曆全中文、不出現英文與句號；內文不小於 11 pt；資訊每頁只留 2 個重點。
- **日曆版型**：參考雷射切割木地圖卡——上方是「作品區」（淺橡木、放要剪下的零件），下方是奶油色「資訊區」，兩個區塊分開。字體改用思源宋體（標題、內文、日期）。右下是磚紅色日期章（月、日、星期）；進度只用七個點表示。零件卡榫左下角放小剪刀圖示，底邊補上虛線。
- **日曆設計流程**：先由主持者出版型，經設計師審核；因質感不足，改由設計師全權接手並反覆迭代（共三輪），最後版型由設計師定案。
- **底座**：六角底座採**平邊朝前**，正前方牆印城市名（思源宋體）；七個插槽依各城市的零件大小與高度計算錯落位置，使每件至少約 25% 可被看見；拿掉插槽編號與拼接連接片；牆側三角膠面朝外、兩側都有；新增「下底」六角板封底。零件與底座皆以 Python（reportlab）程式產生，可依紙厚、尺寸重新輸出。
- **日曆座**：由「插卡」改為「斜面靠放」；台面只微微向後傾。
- **零件圖**：Gemini 生成後，程式自動去背、去掉原圖卡榫並換成統一卡榫、依目標尺寸換算；日曆線稿版由彩色圖轉出並補割線。

## 五、待確認／下一步
1. **試印實測**：卡紙厚度與插槽 0.8 mm 是否合適、三角與梯形膠面是否好組。
2. **第二頁**：城市頁（手機畫面）示意動畫，由我們另做網頁錄螢幕。
3. **內容查證**：日曆介紹文中的年份與說法（龍山寺 1738 創建、「銅鑄龍柱全台唯一」等）付印前須再核對；東京、雪梨尚無日曆介紹文。
4. **雪梨第 5 件**（歌劇院）超出底座邊緣約 9 mm，是否收斂待看實物。
5. **需求驗證**：長輩對城市主題與收藏的興趣、留言機制與審核（法務）仍待處理。
6. **圖片授權**：零件與流程圖為 Gemini 生成，對外正式發布前須確認使用規範。

## 六、資料夾結構
```
明信片專案/
├─ README.md            本檔（進度與歷程）
├─ Gemini生圖提示詞*.md   第一版、完整版、第二版提示詞
├─ 生成流程圖/            Gemini 生成的流程示意圖（第一版、第二版）
├─ 簡報/                 第一版 6 頁、第二版 8 頁簡報（PNG、PDF、HTML 原始檔）；第二版/一頁版/ 為二審一頁簡報
└─ 草模/
   ├─ 三城市七件_提示詞與介紹文.md   三座城市零件的 Gemini 提示詞與台北雙數頁介紹文
   ├─ AI城市圖/          Gemini 生成的三座城市各 7 件零件圖（原圖）
   ├─ 二審影印檔/        最終要印的 PDF（見第三節）
   └─ 程式/              產生展開圖與日曆的 Python 程式（pieces、layout、base、make_calendar5、make_stand 等）
```
**重新輸出**：在 `草模/程式/` 執行 `python extract_pieces.py`（去背）→ `python build_sheets.py`（底座與零件頁）→ `python make_calendar5.py <輸出.pdf> 2`（日曆）→ `python make_stand.py <輸出.pdf>`（日曆座）。需要 Python 套件：reportlab、Pillow、numpy、PyMuPDF、fontTools。
