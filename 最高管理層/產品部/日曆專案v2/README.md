2026-11-25 由 CEO 開啟的新設計方向，CEO 認為很可能是這個產品的**最終定案方向**。

## 規則
- **獨立的新開始**：跟 `日曆專案/`（v1）切割。在這裡討論時，不引用、不比較、不主動提起 v1 的任何版本或內容，除非 CEO 自己問。
- 主題不變：日曆＋不同城市。
- 依日期分資料夾 `YYYY-MM-DD/`，每天的構想、圖、檔案放當天資料夾；每天一份 `進度.md`。
- 製作與資料夾習慣沿用原日曆專案的做法（預覽圖集中、切割檔最後出等），但設計內容一律從這裡重新開始。
