# 03 範疇收斂與 Persona（Scoping & Personas）

**定位**：研究範疇收斂路徑、族群分類象限、Persona A/B/C/D 核心痛點。

## 記錄內容

- **收斂樹狀圖**：從大範圍一路縮小到目標族群的每一個決策點與理由（`scopingPath`）。
- **目標族群定義**：用哪兩條軸線切象限、為什麼選這個象限（`segment`）。
- **Persona**：每位 Persona 一個檔案，代號 `A`、`B`、`C`、`D`…，記錄背景、目標與核心痛點。

## 怎麼記

1. 複製 `persona-template.json` 到 `data/`，檔名建議 `persona-a.json`。
2. `persona` 欄位的代號要和 04、05 階段引用的代號一致，概念提案才能標示「涵蓋哪些 Persona」。
3. `painPoints` 一條一句，盡量用使用者的語氣。
4. 若要記錄「收斂路徑」本身而不是某位 Persona，另開一個檔案，只填 `scopingPath`。
