# 01 宏觀背景（Macro Background）

**定位**：宏觀社會背景、問題因果鏈推導、研究起點定錨。

## 記錄內容

- 社會結構轉折：哪些趨勢改變了研究對象所處的環境。
- 時間真空：生活中被釋放出來、卻沒有被妥善填補的時間。
- 精神連結：人與人、人與社群之間連結的斷裂與重建。
- 因果鏈：從「結構性原因」一路推導到「個人處境」的每一步，並標註資料來源。

## 怎麼記

1. 複製 `causality-template.json` 到 `data/`，一條因果鏈一個檔案。
2. `chain` 依序填入每一環（`step` 編號、`label` 短標、`description` 說明）。
3. `keyInsight` 寫一句「所以我們關心的是…」，作為研究起點。
4. `sources` 放文獻、統計、報導等出處。

首頁的「背景因果總覽」會讀取這裡 `status` 不是 `placeholder` 的資料。
